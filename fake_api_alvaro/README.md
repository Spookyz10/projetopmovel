# Fake API — Álvaro

Conteúdo da API fake individual usada na tela de perfil do CineBrasil.

Para publicar, crie um repositório público chamado `fake_api_alvaro` no GitHub
e envie **o conteúdo desta pasta**, deixando o `db.json` na raiz do novo
repositório. O endpoint será:

```text
https://my-json-server.typicode.com/Spookyz10/fake_api_alvaro/profiles/1
```

O repositório principal mantém esta cópia para documentar e versionar a
estrutura utilizada. A API publicada é acessível por computador, emulador e
telefone físico, pois usa HTTPS e não depende de `localhost`.
